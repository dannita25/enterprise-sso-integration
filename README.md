# Enterprise Single Sign-On (SSO) Solution
Case study covering identity federation, OAuth 2.0, OpenID Connect, ZITADEL, and access management.

## Project Overview
This project involved contributing to the design, development and implementation of an Enterprise Single Sign-On solution for a cybersecurity company.
The main objective was to simplify authentication ofr enterprise customersby exploring how they could use their own identity providers to access the company software, while maintaining secure and manageable access to tehir resources.


## Technologies and Concepts
- Identity Managemente Interface and Third party provider: ZITADEL
- Authentication OpenID Connect (OIDC), OAuth 2.0
- Backend Development: Golang
- Infrastructure as Code: Terraform
- Security: PKCE, JWT token validation, role-based access control (RBAC)
- Architecture: Identity Federation,multi-tenant access management
- Database and ...: AWS
